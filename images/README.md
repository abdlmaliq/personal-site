# Image assets

The site now uses the supplied portrait as a transparent, identity-preserving visual system:

- `abdulmalik-fullbody.png` — high-resolution transparent standing cutout.
- `abdulmalik-headshot.png` — high-resolution transparent head-and-shoulders cutout.
- `abdulmalik-fullbody.webp` — optimized web version used in the hero and contact visual.
- `abdulmalik-headshot.webp` — optimized web version used in the About profile card.

The PNG files are retained as source-quality transparent assets; the WebP files are the browser-facing versions for faster loading. Replace the WebP files only if you want to update the website visuals, and keep the filenames stable.

Future slots remain available for project covers, badge artwork, and an `og-cover.jpg` social sharing image.
