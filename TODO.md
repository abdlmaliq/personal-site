# Build outcomes

## 1. Static foundation and SEO
- [ ] The project is a complete single-page static site using plain HTML, CSS, and vanilla JavaScript and can deploy cleanly to Vercel from GitHub.
- [ ] The initial HTML contains meaningful public body content, semantic sections, a title, meta description, Open Graph tags, Twitter card tags where useful, Person schema markup, and accessible navigation.
- [ ] The site includes `public/manus-routes.json`, `robots.txt`, and `sitemap.xml`; absolute canonical and sitemap URLs remain unguessed until a real public domain is supplied.

## 2. Visual system and responsive behavior
- [ ] The visual direction is futuristic, premium, calm confidence: deep near-black navy (`#070B14`), electric cyan/violet accents, off-white text, editable CSS variables, geometric display typography, Inter body copy, and JetBrains Mono technical labels.
- [ ] The page uses glowing network nodes and lines, grid/circuit patterns, soft grain, glassmorphism cards, and light bloom effects.
- [ ] The layout is fully responsive. Mobile simplifies parallax and removes the custom cursor while preserving smooth interaction and readable content.
- [ ] `prefers-reduced-motion` switches to a clean static layout.

## 3. Motion and interaction
- [ ] The hero has background, mid-ground, and foreground depth layers, staggered name reveal, rotating typewriter-style role line, mouse response, scroll cue, and intro animation.
- [ ] Sections, cards, badges, and visual treatments use eased fade/slide/scale entry and independent parallax offsets where supported.
- [ ] Large outlined section labels drift horizontally; the work rail pins and scrolls horizontally on desktop.
- [ ] Lenis, GSAP, and ScrollTrigger enhance smoothing and scroll-linked animation without making content unavailable if scripts fail.
- [ ] The page includes a custom cursor/trail on pointer devices, scroll progress, morphing compact nav, smooth anchors, tilt on interactive cards, and keyboard-accessible controls.

## 4. Portfolio content
- [ ] Hero, About, What I Do, Certifications, Selected Work, Testimonials, Contact, and Footer sections include the approved Abdulmalik Afegbua copy and links.
- [ ] About includes the University of Benin (2014), IT support to WordPress story, count-up stats “10+ years in tech” and “5 organizations served”, and the five-organization logo strip.
- [ ] What I Do includes Hardware Troubleshooting, Web Design, Graphics Design, Network Administration, Cybersecurity, Microsoft Office 365 Administration, plus the requested Tech Stack chips.
- [ ] Certifications include AWS, Google IT Support, Google Cybersecurity, Google AI Essentials, and ISC2; the supplied Credly links are preserved where provided.
- [ ] Work includes GAIA Africa Club, TPA Studio marked “In progress”, and Nigerian Maritime Law Association with the supplied links and descriptions.
- [ ] Testimonials include the supplied Automattic and GAIA Africa Club quotes in a draggable/keyboard-operable carousel.
- [ ] Contact includes a working direct email link, social links, and the requested footer text.

## 5. Handoff and validation
- [ ] `README.md` explains content editing, asset replacement, local preview, and GitHub-to-Vercel deployment.
- [ ] `images/README.md` documents simple filenames for future avatar, project, and badge assets.
- [ ] Preview responds on port 3000, the route manifest returns valid JSON, diagnostics are registered, and the final code has no confirmed actionable issues.
- [ ] Remaining assumptions/placeholders are listed for the user, especially the production domain, AWS Credly URL, and project-specific imagery.
